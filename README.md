# Welcome To IlmPath

# An E-Learning React Native Application to learn the Holy Quran

# To Setup navigate to the IlmPath Folder and run following command

`npm i`

# This will download the dependencies of the project.

# To setup database navigate to the backend Folder inside the IlmPath folder and run following command.

`docker-compose up --build`

# To start application navigate back to IlmPath folder and run following command

`npm start`
